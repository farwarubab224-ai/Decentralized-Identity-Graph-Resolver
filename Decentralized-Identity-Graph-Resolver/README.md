# Decentralized Identity Graph Resolver

A Java-based project for managing and resolving decentralized identities using graph data structures.

## Technologies

- Java 21
- JavaFX
- Maven
- SQLite
- JSON
- Git and GitHub

## Planned Features

- Decentralized Identity (DID) creation
- Identity linking
- DID document generation and resolution
- Digital signature verification
- Identity graph visualization
- Shortest path algorithms
- Cycle detection

## How to Run

Make sure Java 21 and Maven are installed.

```bash
mvn clean javafx:run
```
